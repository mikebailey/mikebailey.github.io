# Card-page design archive

These are the September 23 design studies and public-domain reference prints
that preceded the selected Booth-map contact page. The chosen page is already
on master at 55348c5; this archive does not replace it.

The generators use paths relative to this directory. Source-art attribution is
recorded in prints/sources.json. The complete archive is about 51 MB and is
retained here to preserve the alternatives and reproducibility; no single file
exceeds 10 MB. These previews are excluded from the Jekyll site in _config.yml.
Repository source remains public, just like the existing website source.
